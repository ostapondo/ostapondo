Спосіб перший

Просто тягніть.

Зони світяться, поки вікно в руці. Затисніть ще й ⌘ — воно ляже одразу на дві.

Спосіб другий

Або клавішею.

Дев'ять зон живуть на цифрах. Нуль — кнопка «вибач», повертає вікно туди, де воно було до Plonk.

Plonk

To plonk is to set a thing down exactly where it belongs.

version0.2.4 macOS13+ swift6 deps0 mcp20 tools

A Mac window manager with zones you draw yourself. Put a window in one by dragging it, by shortcut, by voice, or by asking an agent over MCP.

Three ways to move a window

Drag itZones light up. Hold ⌘ for two at once
⌃⌥1 … 9⌃⌥0 puts it back
⌃⌥VSay it. Offline, on-device
Ask an agent20 MCP tools

Install

brew install --cask ostapondo/plonk/plonk

macOS 13 or newer, Apple silicon. Grant Accessibility when it asks, then relaunch.

What you get

ZonesOverlap them, gap them, hide the numbers, keep a list of apps Plonk never touches
WorkspacesMonitors are keyed by UUID, so unplugging one does not scramble them
VoiceCommon commands run in the app, offline. Recognition is on-device

Чотири кольорові картки замість таблиці «три способи» — найдешевша правка з найбільшим ефектом: один SVG, який однаково читається на телефоні й на десктопі, у світлій і темній темі GitHub.
