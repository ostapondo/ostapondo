Privacy

No account.
No cloud.
No telemetry.

The API binds to 127.0.0.1, refuses anything carrying headers a browser cannot suppress, and is gated on a token only you can read.

None of that has to be taken on trust. Releases are built on GitHub's runners and ship with an attestation:

gh attestation verify Plonk-0.2.4.zip -R ostapondo/plonk
  • No Full Disk Access, no Automation, no Keychain
  • Config is plain JSON you can open and read
  • The one outbound connection is the update check, and it switches off

To plonk is to set a thing down exactly where it belongs. Put a window in a zone by dragging it, by shortcut, by voice, or by asking an agent over MCP.

Three ways to move a window

InputWhat happens
dragZones light up as you move a window. Hold ⌘ and it takes two at once
⌃⌥1 … ⌃⌥9The numbered zones on that screen
⌃⌥0Puts a window back where it was before Plonk touched it
⌃⌥VHold and name the place. Offline, on-device
