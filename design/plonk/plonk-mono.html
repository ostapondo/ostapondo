PLONK
put it there.

A Mac window manager with zones you draw yourself.
macOS 13+ · Swift 6 · MIT · 0 dependencies

12345
version0.2.4 macOS13+ swift6 deps0 mcp20 tools

To plonk is to set a thing down exactly where it belongs. Put a window in a zone by dragging it, by shortcut, by voice, or by asking an agent over MCP.

Three ways to move a window

InputWhat happens
dragZones light up as you move a window. Hold ⌘ and it takes two at once
⌃⌥1 … ⌃⌥9The numbered zones on that screen
⌃⌥0Puts a window back where it was before Plonk touched it
⌃⌥VHold and name the place. Offline, on-device

Install

brew install --cask ostapondo/plonk/plonk

macOS 13 or newer, Apple silicon. Grant Accessibility when it asks, then relaunch.

For agents

claude mcp add plonk -- npx -y plonk-mcp

Frames are fractions of a monitor's visible area, origin top-left, so "left 60%" is {x: 0, y: 0, w: 0.6, h: 1}.

Банер тут не картинка з текстом, а схема набору зон із номерами — читач бачить продукт раніше, ніж перший рядок опису. Бейджі стають чорно-білими, крім одного фіолетового: MCP. Це те, чим Plonk відрізняється від Rectangle і Magnet.
