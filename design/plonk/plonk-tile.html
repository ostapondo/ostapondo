Способи покласти вікно

Перетягніть.

Зони підсвічуються, поки ви тягнете. Затисніть ⌘ — вікно займе одразу дві.

Натисніть.

⌃⌥1⌃⌥←⌃⌥0

Дев'ять зон на цифрах. Нуль повертає вікно туди, де воно було до Plonk.

Скажіть.

⌃⌥V

«Zone three». Розпізнавання йде в застосунку, офлайн, на пристрої.

Приватність

Ні акаунта. Ні хмари. Ні телеметрії.

API слухає лише 127.0.0.1 і закритий токеном, який читаєте тільки ви. Єдине з'єднання назовні — перевірка оновлень, і її можна вимкнути.

І це не треба брати на віру. Релізи збираються на раннерах GitHub і їдуть з атестацією.

gh attestation verify Plonk-0.2.4.zip -R ostapondo/plonk

03 README

GitHub не дає стилів. Тому дизайн приходить банером-SVG, кольоровими бейджами і схемами замість скріншотів.

ostapondo / Plonk · README.md

Plonk
— клади рівно.

A Mac window manager with zones you draw yourself.

version0.2.4 macOS13+ swift6 deps0 mcp20 tools

To plonk is to set a thing down exactly where it belongs. Put a window in a zone by dragging it, by shortcut, by voice, or by asking an agent over MCP.

Three ways to move a window

123
Drag itZones light up as you move a window. Hold ⌘ and it takes two of them at once
⌃⌥1 … ⌃⌥9The numbered zones on that screen. ⌃⌥0 puts a window back where it was
⌃⌥VHold and name the place. Runs in the app, offline, on-device

Install

brew install --cask ostapondo/plonk/plonk

macOS 13 or newer, Apple silicon. Grant Accessibility when it asks, then relaunch.

Три правки, які роблять README «своїм»: банер малюється як SVG (той самий чорний фон і фіолет), бейджі перефарбовані в палітру замість дефолтних сірих, а замість гіфки з інтерфейсом — схема зон, яка читається навіть у мобільному GitHub.

· Що це коштує

Один CSS-файл на сайті, один SVG-банер у репозиторії, і кольори SwiftUI у застосунку. Жодного нового залежності, жодного шрифта з мережі: скрізь SF Pro, рідний шрифт мака — того самого, для якого написаний Plonk.
